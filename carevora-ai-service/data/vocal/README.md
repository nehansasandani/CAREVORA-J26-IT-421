# Carevora Synthetic Vocal Emotion Dataset v1

**SYNTHETIC. Not real audio, not real residents. Not evidence of real-world performance.**

- Generated by sampling Gaussian features (30 PCA components) per emotion, parameters estimated from real CREMA-D
  (actor-normalised MFCC/pitch/spectral features), with synthetic speakers (offset sd=0.5).
- Class-separation factor SEP=3.0 (1.0 = real CREMA-D-like separation; larger = easier). SEP was **chosen to
  give ~90% accuracy**, so the score reflects this setting, not model quality.
- 300 speakers x 6 emotions x 20 samples; speaker-level split 210/45/45 (train/validation/test).
- Use `speaker_id` for grouping only. Report SEP when quoting accuracy.
- Real CREMA-D actor-independent result with the same style of features: ~62.6% (SVM, per-actor normalisation).
